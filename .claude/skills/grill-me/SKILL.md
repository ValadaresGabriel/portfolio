---
name: grill-me
description: Entrevista o usuário sobre uma ideia ou feature até ela ficar clara o bastante para virar spec. Use quando o usuário pedir "grill me", "me questiona", ou quiser refinar uma ideia antes de construir.
---

Objetivo: entender o que o usuário quer construir, sem suposições escondidas.

1. Leia o que já existe no projeto (incluindo `specs/`) antes de perguntar. Nunca pergunte algo que você pode descobrir sozinho.
2. Faça no máximo 3 perguntas por rodada, numeradas, só sobre decisões que dependem do usuário. Para cada uma, dê sua recomendação, escrita de forma que "sim" a aceite:

   **Q1 - <título>**: <pergunta curta>
   ➡️ Recomendo: <resposta>

3. Espere as respostas. Repita só enquanto houver dúvida que muda o que será construído. Projeto simples = poucas rodadas.
4. No fim, resuma em tópicos o que ficou decidido e pergunte: "Posso escrever a spec?" Se sim, use a skill `spec`.

Não escreva código durante a entrevista.
